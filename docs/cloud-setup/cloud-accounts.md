# Cloud Accounts

To discover and manage your resources, CloudAvocado connects to each of your cloud provider accounts. This page lists the authentication methods supported for each provider.

## Authentication Methods

| Provider      | Auth Methods                                                            |
| ------------- | ----------------------------------------------------------------------- |
| AWS           | Cross-account IAM role assumed with an external ID; IAM user access key |
| Google Cloud  | Service account key file (JSON)                                         |
| Azure         | Service principal (app registration) with a client secret               |
| MongoDB Atlas | Service account with a client ID and client secret                      |
